# ui/public/ - Static Resources

Static files for the web application.

## Folder Structure

```
public/
└── css/
    └── style.css    # Custom stylesheet
```

## Resource Management

- **CSS**: Custom styles and Bootstrap extensions
- **Images**: Logos and icons (to be added in the future)
- **JavaScript**: Client-side scripts (to be added in the future)

## External CDN Usage

The following resources are loaded from CDN:
- Bootstrap 5 CSS/JS
- Bootstrap Icons

## Custom Styles

`style.css` contains Saphira-specific style adjustments.
